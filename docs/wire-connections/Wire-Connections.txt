Z-Boat Wire Connections
=======================

Reformatted from Wire Connections.docx. Original English technical terms and cable labels are retained; grammar,
headings, units, and layout have been standardized.

Record status: These are observations reported in the original document, not independently verified wiring
specifications. Open questions and uncertain descriptions remain marked below. Interface names in the index do
not establish electrical signal direction.

4.1 Cable branching
-------------------

The original description says that the 24 V cable assembly splits into two smaller cables:

1. One branch connects to TDM-E.
2. The other branch splits into six smaller cables, reported as connected to the battery at the front of the
  boat.

The diagram records that description only. Line connections do not specify current direction, polarity, pin
assignments, or a validated electrical topology.

24 V cable assembly described in the source
|
+-- Branch 1 ---- TDM-E
|
`-- Branch 2 ---- Six smaller cables ---- Front-of-boat battery

11. Image sources and duplicate handling
----------------------------------------

- All 31 Word image occurrences are accounted for by 27 retained primary figures.
- 22 primary figures use matching, higher-resolution GitHub photos; five use the best available embedded Word
  images.
- The 10 other distinct GitHub photos are retained as supplementary figures S01-S10.
- The repository edition reuses the 32 existing photos at the repository root and adds only the five Word-only image files. Image bytes, resolution, and existing
  annotations are preserved; images have not been upscaled or regenerated.
- Four repeated-photo groups from Word are consolidated. Cross-references replace repeated image blocks;
  associated connection descriptions remain in place.
- The GitHub upload has no byte-identical or decoded-pixel-identical files. Annotated variants and different
  camera views are retained. No repository photos were deleted.

The linked photo inventory records source identifiers for traceability. Word media numbers refer to
word/media/imageN.jpeg, not page numbers.
